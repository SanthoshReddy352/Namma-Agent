# Writing

Good drafts start from the reader: who reads it, what they must do after.

## Procedure

1. **Pin down audience, purpose and tone** from the request and what you know
   about the user (memory). Ask ONE short question only if the audience or goal
   is genuinely unclear; otherwise draft and state your assumption.
2. **Draft** with the ask or bottom line first, short paragraphs, concrete
   details (dates, numbers, names), and a clear next step.
3. **Offer the draft ready to copy** in a code-free block of plain text, then
   one line on what you optimized for (e.g. "kept it under 120 words, warm but
   direct").
4. **Edits:** keep the user's voice; show only the changed version unless they
   ask for a diff.

## Gotchas

- Never send anything (email, message) without the user's explicit go-ahead.
- Don't pad: cut filler phrases ("I hope this finds you well") unless the
  user's style uses them.
